# تغییرات VIRA V3

- خرید اشتراک از کیف پول پیاده‌سازی شد؛ طرح‌ها از تنظیمات پنل مدیریت قیمت می‌گیرند.
- کسر موجودی و ایجاد اشتراک در تراکنش `BEGIN IMMEDIATE` انجام می‌شود تا دو خرید هم‌زمان موجودی منفی نسازند.
- سابقه خرید اشتراک در جدول مستقل `subscription_purchases` نگهداری می‌شود؛ ساختار قدیمی `wallet_ledger` و داده‌های قبلی تغییر نکرده‌اند.
- مسیر PHP پرداخت، Authority را به امضای مختص همان invoice پیوند می‌دهد. ترکیب Authority فاکتور اول با لینک فاکتور دوم باید رد شود.
- ساخت تنظیمات اولیه به Sandbox پیش‌فرض تغییر کرده است.
- Helper پیش از افزودن کانال، وضعیت دسترسی کاربر تلگرام را نیز بررسی می‌کند.
- راهنمای نصب برای استخراج ZIP با فایل‌های ریشه اصلاح شد.

## API جدید

`GET /api/public/subscription-plans`

`GET /api/subscriptions` (نیازمند Bearer token کاربر)

`POST /api/subscriptions/purchase` (نیازمند Bearer token کاربر)

Body:
```json
{"plan_code":"monthly"}
```

مقادیر مجاز: `monthly`، `quarterly`، `yearly`.

## هشدار استقرار

این بسته فقط Backend/Server است. سورس React/Capacitor در ورودی موجود نبود، پس APK و UI شارژ تولید نشده است. قبل از پرداخت زنده، تست pytest و پرداخت Sandbox را روی محیطی با وابستگی‌های کامل اجرا کن.
